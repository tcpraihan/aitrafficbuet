# Photos

Drop photos here (.jpg, .jpeg, .png, .webp, .gif, .avif), then commit and push.
They appear in the website gallery automatically — no need to edit js/data.js.

- Caption = file name: `shahbagh-site-visit.jpg` → "Shahbagh site visit"
- Order = alphabetical. Prefix numbers to control order: `01-pcb.jpg`, `02-install.jpg`
  (the number is hidden from the caption).
- Keep each photo under ~400 KB so the page loads fast.
